# 签名类型

`signature.yaml` 的 `type` 和 `return_type` 只能填下表「填这个」列里的类型。`statement.md` 讲有哪些参数、返回什么，要和 `signature.yaml` 的名字、顺序对得上；写「整数」「数组」，不要把本表类型名抄进 `statement.md`。

| 填这个 | 表示什么 | 这个参数上的数怎么写进 meta.yaml | 输入规模看什么 |
|---|---|---|---|
| `int` | 32位整数（默认填这个） | 写最小和最大（整数） | 这个数本身（仅当它写在边列表前面，表示有几个点） |
| `long` | 64位整数 | 写最小和最大（整数） | 这个数本身（仅当它写在边列表前面，表示有几个点） |
| `float` | 一个小数 | 写最小和最大（小数） | 不表示输入规模 |
| `bool` | true 或 false | 不用写 | 不表示输入规模 |
| `str` | 字符串 | 写能出现哪些字符 | 长度 |
| `List[int]` | 整数数组 | 写最小和最大（整数） | 长度 |
| `List[long]` | 64位整数数组 | 写最小和最大（整数） | 长度 |
| `List[float]` | 小数数组 | 写最小和最大（小数） | 长度 |
| `List[bool]` | bool数组 | 不用写 | 长度 |
| `List[str]` | 字符串数组 | 写能出现哪些字符 | 长度 |
| `List[List[int]]` | 二维整数数组（包括矩阵、格子、边的列表） | 写最小和最大（整数） | 行数；若前面写了有几个点，规模是点的个数，而非点的连线的个数 |
| `List[List[long]]` | 二维64位整数数组（包括矩阵、格子、边的列表） | 写最小和最大（整数） | 行数；若前面写了有几个点，规模是点的个数，而非点的连线的个数 |
| `List[List[float]]` | 二维小数数组 | 写最小和最大（小数） | 行数 |
| `List[List[bool]]` | 二维bool数组 | 不用写 | 行数 |
| `List[List[str]]` | 二维字符串数组 | 写能出现哪些字符 | 行数 |

不要填三层列表、`long long`、`int64`。不要出链表节点、二叉树节点。

返回 `float` 或返回值/参数里含 `float`：比较返回值时一律绝对/相对误差约 `1e-6`，与 `compare: exact` 无关。`int` / `long` 仍逐值相等。`compare` 只表示顶层列表是否允许乱序。

输入规模、每个参数的范围怎么填，见 `{根}/rules/files.md`。
