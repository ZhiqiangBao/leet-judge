# 客户端操作

[English](client.en.md)

客户端是打开评测网页的设备：Windows、macOS、手机，或评测机本机浏览器。客户端不安装 Python / gcc / g++，也不保存账号。账号、题库和判题都在评测主机上。

服务端部署与启停见 [server.md](server.md)。还没有评测机见 [host.md](host.md)。

## 打开网站

浏览器访问：

```text
http://<评测机局域网IP>:8080
```

双系统 / 独立 Ubuntu：IP 由评测主机执行 `hostname -I` 得到。必须带端口 `8080`。

WSL 当评测机：在 **这台 Windows** 上用 `http://127.0.0.1:8080`。其它设备默认连不上，见 [host.md](host.md)。

若地址是 `localhost:5173`，则连的是前端开发服务器，不是家里那台评测机。

## 注册与登录

评测主机本机浏览器打开 `http://127.0.0.1:8081` 注册**管理员**（局域网打不开这个端口）。`:8080` 上的注册永远是普通用户，即使是第一个账号。管理员账号建好后，可在任意客户端打开 `:8080` 登录，顶栏变为「题目 / 数据 / 题库 / 手册」。

用户名：3–32 个字符，字母、数字、下划线。密码至少 4 位。同一用户名可在任意客户端登录，都是评测主机上的同一个账号。

## 做题

1. 登录后进入题目列表，可用搜索、难度和知识点筛选。状态：已通过为 `AC`，做过未通过为「尝试过」。
2. 打开题目：左侧题面，右侧编辑器。
3. 语言下拉是本题能交、且评测机已装好的语言。某语言没装编译器：灰色，提交为 `NA`。常见可见：Python 3、C、C++20、JavaScript、TypeScript、Go、Rust、Zig（视本机是否装了对应工具；Go / Rust / Zig 见 [toolchains.md](toolchains.md)）。
4. 按空模板补全函数：Python / C++ / JavaScript / TypeScript 是 `class Solution` 的方法；C 是普通函数，没有 `class Solution`。不要自行编写 `main`（C / C++ / Go 的 `func main`）。Go 模板里的 `package main` 保留。
5. **测试**：只跑题面示例，结果不计成绩、不进排行、不改变「已通过」。评测机忙的时候按钮会多转一会儿。
6. **提交**：跑全部测例（含隐藏），写入提交记录；全过才算通过并参与该语言耗时榜。忙的时候页面会等到出结果。

判定：

| 结果 | 含义 |
| --- | --- |
| `AC` | 全部测例通过 |
| `WA` | 答案错误 |
| `TLE` | 超时 |
| `MLE` | 超出内存 |
| `RE` | 运行时错误 |
| `CE` | 编译失败 |
| `NA` | 语言不可用 |

公开测例失败时显示输入、期望与输出。隐藏测例只显示序号。

顶栏「成绩」列出本人各题、各语言最好 AC 耗时与名次。题目页左侧有当前语言的排行榜。编辑器会按账号自动保存草稿，下次打开同一题同一语言会恢复离开前的代码。

「提交记录」页列出当前登录用户自己的历史。测试运行不会出现在提交记录或成绩里。这两项只出现在普通用户顶栏；管理员顶栏用「数据」看全站汇总。

## 管理员（网页）

顶栏 **题目 / 数据 / 题库 / 手册**。题目页和普通用户相同。数据、题库、手册：做什么、点完出现什么、下一步，见 [admin.md](admin.md)。

不要一边用网页写盘、一边用 Git 改同一题。

## 接口文档

```text
http://<评测机IP>:8080/docs
```

供查看 API，不是做题页。
