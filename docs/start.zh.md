# 买完题包之后

[English](start.en.md)

给已经装好评测机、刚下到 zip 的人。按顺序做完即可开考。zip 内同文是 `GETTING-STARTED.zh.md`。

## 1. 确认评测机在跑

浏览器能打开 `http://<主机IP>:8080`。打不开见 [host.md](host.md)、[server.md](server.md)。

## 2. 用管理员账号登录

管理员只能在评测机本机 `http://127.0.0.1:8081` 注册。之后在 `:8080` 登录，顶栏是「题目 / 数据 / 题库 / 手册」。

## 3. 导入 zip

**题库 → 本机导入** → 选下载到的 zip，不用先解压。页面列出写入的题目名即成功。

同名题目要换成这一包，勾选「覆盖评测机上的同名题目」。

## 4. 发布给考生

导入后题目默认只有管理员能看见。到 **题库 → 发布**，对要考的题点「发布」。

不点发布：考生登录后题目列表是空的。

## 5. 让考生做题

考生在 `:8080` 自己注册（不是管理员）。他们只能看到已发布的题。

- **测试**：只跑题面示例，不计成绩。
- **提交**：跑隐藏测例。失败只显示第几号，不显示输入。
- 同一场可以重复提交，以最好一次通过为准。

你在「数据」里看每题、每人的提交。不要把隐藏测例发到聊天或课件里。

## 退款

商店规则：7 天内、且还没有用隐藏测例做正式提交，可以退。已经提交过隐藏测例的不退。
